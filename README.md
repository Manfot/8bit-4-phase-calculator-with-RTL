# 8bit-4-phase-calculator-with-RTL
this project is about a calculator made purely from resistors, transistors and self made led matrix for 7 segment display.everything will be hand soldered and assembled
this all started a couple years back when i had a side hobby about designing a calculator in a notebook. i didnt think of making it then but as i added to this notebook, the idea of making it reality instead of symbols became bigger. a few days back, i found that notebook again and i started adding on it again. and then i decided that instead of making it in logic gates, i would get a more fun and long approach,which is making it from the purest materials you can get. resistors and transistors for logic and then leds for custom made matrixes. the goal is to make this calculator reality and it completes all 4 main calculations (addition,subtraction,multiplication and division) and display the selected numbers, calculation type and results on actual displays that i will make myself again. i hope it gets approved from hack club but even if it doesnt, it was a really fun opportunity to learn the most deep and advanced levels of both boolean algebra and computing logic, which is kind of my passion
